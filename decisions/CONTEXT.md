# decisions — Architecture Decision Records

One file per decision: `NNNN-kebab-title.md` with frontmatter `status: proposed | accepted | superseded`, `date`, and `supersedes` / `superseded_by` when relevant. `_index.md` is generated by `_scripts/gen-indexes.sh` — never hand-edit it.

Promotion gate: an observation made during a task is written in the PR description. It becomes a decision only when a human merges an ADR (or a line in `docs/`) that records it. Contradicting an accepted ADR = write a new ADR that supersedes it; never silently edit the old one.

The founding review that these ADRs distil: `2026-08-17-foundation-ultra-review.md`.
