# Schema — map cards

| `type:` | Lives at | Carries |
|---|---|---|
| object | `objects/<slug>.md` | cluster, universe (live/leftover/ghost), status (stub/verified/stale), entity path, Hits / Does not hit |
| process | `processes/<slug>.md` | consumes/produces links, numbered steps with citations, Hits / Does not hit |

Slugs kebab-case. `objects/_index.md` (when it exists) is generated by `_scripts/gen-indexes.sh`.
