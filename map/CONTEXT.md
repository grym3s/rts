# map — how to walk

1. Start at `CLAUDE.md` (catalog). 2. If the noun has a card, open only that card. 3. For a change, open `effects/CONTEXT.md` and follow its rows to the folder contracts it names. Stop there.

Universes and name collisions are defined once in the root `CONTEXT.md`; this map uses them unchanged.

Card rules: copy `_templates/object.md` / `process.md`; cite `path:line`; `status: verified` requires a date and commit hash; `stale` is honest, a wrong date is not. "If you change this" is first-order only — Hits / Does not hit. Never paste behaviour into a card; point at the file.
