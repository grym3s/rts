# tools/sim-host — engine-independent sim process

Owns: a stdio newline-delimited-JSON host exposing the composed SimWorld to non-.NET engines (Unreal first). One request in, one response out per line. Kinds: `init` (scenario-v2 object minus commands/ticks/assert → snapshot at tick 0), `step` (tick + tick-stamped scenario-format commands → advances EXACTLY one tick, returns snapshot + events), `reset` (T07: drops the world so a following `init` starts the match over; `init` on a live world is `already_initialized`), plus bounded errors (never crashes the process).
Protocol: `protocolVersion` must equal 1; request `tick` is the sim tick the commands execute AT (after init the host is at 0; commands stamped T ride the step that leaves Tick==T, matching the scenario runner's `t = 0..ticks-1` loop). Duplicates/gaps/command-mismatched stamps are recoverable `ok:false` errors; the world only advances on accepted steps, and a rejected request NEVER discards an initialized world (every error path is bounded to before `World.Step`). Command `target` is polymorphic by type: move/attack-move = `[x, y]`; attack = integer entity id (strict — non-integer/missing target is `malformed_request`). Response `state.hash` is an exact lowercase 16-hex-digit JSON **string** (the runner/CI format; raw JSON numbers lose precision >2^53-1 in JS consumers).
Reads: `content/units`, `content/buildings` catalogs, scenario JSON on stdin. Writes: response lines on stdout.
Composition is a verbatim copy of `tools/scenario/Program.cs` wiring; determinism parity with the runner's golden hashes is asserted by `tools/sim-host.tests` — if wiring drifts, those tests fail.
Tests: `dotnet test tools/sim-host.tests`. CI runs `make check test`.
Do NOT: add game rules, duplicate rule logic, own tick looping beyond one step, or mutate scenario semantics. Replace a live world silently: a second `init` stays `already_initialized` until a `reset`.
Events (T09, additive to v1): each is `{tick, kind, subject, target, amount, faction}`; kinds `shot` (amount = damage, Q32.32 raw), `death` (target = killer, faction = dead unit's), `match_end` (faction = winner, -1 draw). Economy (T30, additive to v1): `state.factions[] = {faction, credits, powerSupply, powerDraw}` (one row per faction: 0 coalition, 1 hegemony, 2 ascendant since T27) (net = supply − draw, low power when negative); `state.veins[] = {id, x, y, pool}` (pool = credits left); `state.refineries[] = {faction, x, y}` (legacy scenario drop-off points only; refinery buildings are ordinary building units); building units add `constructionTotal`, and with a queue `queueHeadRemaining` / `queueHeadTotal` (ticks). Buildings (T32) add `footprintW` / `footprintH` (cells; the unit sits at the footprint centre, T31); an MCV carries `deploysTo` (its yard's building id). Command `deploy` (T32) = `{tick, faction, type:"deploy", unit:<id>}`. Command `rally` (T37) = `{tick, faction, type:"rally", building:<id>, at:[x,y]}`; a building with a rally point carries `rally = [x, y]` (Q32.32 raw) and units it trains spawn with a move order there. Command `harvest` (T38) = `{tick, faction, type:"harvest", units:[ids], vein:<id>}`; harvester rows carry `loadCapacity` (a full load in credits). Terrain (T25): a scenario `map` may carry `terrain` rows (`.` land, `~` water, `#` cliff, `=` bridge) as well as or instead of `blocked`; unit rows carry `domain` (`naval` / `hover` / `air`; absent = land). Build menus (T36, additive): the `init` reply carries `catalog = {buildings:[{id, name, faction, category, cost, buildTicks, prereq, power, footprintW, footprintH}], units:[{id, name, faction, cost, buildTicks, builtFrom, deploysTo, harvest, domain}]}`; request kind `query` = `{protocolVersion, kind:"query", query:{type:"place", faction, building, at:[x,y]}}` answers `query = {allowed, reason, x, y, w, h}` (reason ok / wrong_faction / prereq / blocked / occupied / radius / credits, T25 water / shore; the footprint rect in cells) from `ProductionSystem.CheckPlace`, read-only: it never advances the world and carries no state. A step with `"debug": true` (T20, opt-in) adds `state.debug = {stepMicros, units: [{id, state, target, path}]}`: state is idle/move/attack-move/attack/guard/returning, target -1 = none, path = remaining waypoints as [x, y] Q32.32 raw (max 32), stepMicros = World.Step wall time. Read-only, never hashed. Each snapshot unit carries `hp` and `maxHp` (Q32.32 raw; T15 health bars). The snapshot carries `state.match = {over, winner, endTick}` (T06). Names come from `HostedWorld.KindName`; payloads come from the sim's SimEvent contract, never host invention.
